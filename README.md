# Nexa Manufacturing Unit India

### Responsive React Landing Page

## Project Overview
Nexa Manufacturing Unit India is a modern, responsive, single-page web application developed to create a professional online presence for a manufacturing business.

The website focuses on a clean user interface, mobile-friendly layouts, and an improved user experience.

## Project Features
- Modern and professional landing page.
- Responsive design for desktop, tablet, and mobile.
- React functional components.
- Registration form interface.
- Reusable component structure.
- Semantic HTML5 elements.
- Clean and maintainable CSS.
- Optimized frontend performance.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vercel (Deployment)
- GitHub (Version Control)

## Project Structure
The application is organized into reusable React components.

- Header – Website navigation.
- Hero – Main landing page section.
- Registration Form – User registration interface.
- Footer – Website footer information.

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/chaitanyapriya440-star/nexa-manufacturing-website.git`

2. Navigate to the project folder:

   `cd nexa-manufacturing-website`

3. Install dependencies:

   `npm install`

4. Start the development server using the command configured in package.json.
